# ☕ Coffee Shop Sales Analysis Using SQL

## Project Overview

This project demonstrates SQL-based data analysis on a coffee shop database. The objective is to extract meaningful business insights from sales, customer, product, and city data using SQL queries.

The project contains **30 business-focused SQL queries** covering revenue analysis, customer behavior, product performance, city-wise sales, ranking, window functions, Common Table Expressions (CTEs), and database views.

## Database

**Database Name:** `coffee_db`

### Tables

* `sales`
* `customers`
* `products`
* `city`

## Project Objectives

* Analyze overall business performance.
* Measure total revenue and order volume.
* Evaluate customer purchasing behavior.
* Identify top-performing products.
* Compare sales across different cities.
* Generate monthly sales reports.
* Calculate customer lifetime value.
* Demonstrate advanced SQL techniques for business analytics.
