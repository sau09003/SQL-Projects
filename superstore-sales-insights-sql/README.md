# 📊 Superstore Sales Analytics (SQL Project)

## 🧾 Overview

This project demonstrates SQL-based analysis on a retail Superstore dataset.  
The objective is to extract meaningful business insights using SQL queries ranging from basic filtering to advanced analytical techniques.

The analysis focuses on sales performance, profitability, customer behavior, product trends, and time-based insights.

---

## 📂 Dataset

The dataset used in this project is `superstore_sales`, which contains real-world retail transaction data:

- Order and Shipping Details  
- Customer Information  
- Product Categories and Sub-Categories  
- Sales, Profit, and Discount values  
- Region, State, and City information  

---

## 🎯 Objectives

- Analyze overall sales and profit performance  
- Identify top customers and products  
- Evaluate regional and category-wise performance  
- Study time-based sales trends  
- Apply advanced SQL techniques for business insights  

---

## 🧠 SQL Concepts Used

- SELECT, WHERE, ORDER BY  
- Aggregate Functions (SUM, COUNT, AVG, MIN, MAX)  
- GROUP BY and HAVING  
- Date Functions (YEAR, MONTH, QUARTER, DATEDIFF)  
- Subqueries  
- Window Functions:
  - RANK()
  - DENSE_RANK()
  - ROW_NUMBER()
  - LAG()  
- Cumulative and Running Total Analysis  

---

## 🔍 Key Insights

- Sales distribution is highly concentrated among top customers and products  
- Certain categories contribute significantly more profit than others  
- Some products generate negative profit despite high sales  
- Regional performance varies significantly across states  
- Seasonal trends impact monthly and quarterly sales  
- Shipping time remains consistent but has occasional delays
